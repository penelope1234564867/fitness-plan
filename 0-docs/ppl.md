  ---
  PPL 按周天数的经典分化

  3天/周（最经典）

  就是你现在 test 里的：推 / 拉 / 腿 各一天

  ┌──────────┬──────────────────────────────────────────┬────────────────────────────────────┐
  │    天    │                 训练内容                 │              目标肌群              │
  ├──────────┼──────────────────────────────────────────┼────────────────────────────────────┤
  │ Day 1 推 │ 胸部 + 肩部(三角肌) + 肱三头肌           │ 胸大肌、三角肌前/中束、肱三头肌    │
  ├──────────┼──────────────────────────────────────────┼────────────────────────────────────┤
  │ Day 2 拉 │ 背部 + 肱二头肌 + 斜方肌                 │ 背阔肌、菱形肌、肱二头肌、斜方肌   │
  ├──────────┼──────────────────────────────────────────┼────────────────────────────────────┤
  │ Day 3 腿 │ 股四头肌 + 腘绳肌 + 臀大肌 + 腹部 + 小腿 │ 股四、股二、臀大肌、腹直肌、腓肠肌 │
  └──────────┴──────────────────────────────────────────┴────────────────────────────────────┘

  动作特点：推日全是"推"类动作，拉日全是"拉"类，腿日全是下肢。肌群完全不重叠，保证 48h 恢复。

  ---
  4天/周

  PPL 在 4 天时会有一个肌群练两次。常见方案：

  ▎ 方案 A：推 / 拉 / 腿 / 全身（推荐，均衡）

  ┌────────────┬───────────────────────────────────┬──────────────────────────────┐
  │     天     │             训练内容              │             说明             │
  ├────────────┼───────────────────────────────────┼──────────────────────────────┤
  │ Day 1 推   │ 胸部 + 肩部 + 肱三头肌            │ 正常推日                     │
  ├────────────┼───────────────────────────────────┼──────────────────────────────┤
  │ Day 2 拉   │ 背部 + 肱二头肌 + 斜方肌          │ 正常拉日                     │
  ├────────────┼───────────────────────────────────┼──────────────────────────────┤
  │ Day 3 腿   │ 股四头肌 + 腘绳肌 + 臀大肌 + 小腿 │ 正常腿日                     │
  ├────────────┼───────────────────────────────────┼──────────────────────────────┤
  │ Day 4 全身 │ 推类(轻) + 拉类(轻) + 腹部        │ 容量减半，挑重点动作，加腹肌 │
  └────────────┴───────────────────────────────────┴──────────────────────────────┘

  ▎ 方案 B：推 / 拉 / 腿 / 推（优先练胸）

  第 4 天重复推日，适合想重点强化胸/肩的人。

  ---
  5天/周

  ▎ 推 / 拉 / 腿 / 推(辅助) / 拉(辅助)

  ┌──────────────┬───────────────────────────────────┬────────────────────┐
  │      天      │             训练内容              │        侧重        │
  ├──────────────┼───────────────────────────────────┼────────────────────┤
  │ Day 1 推(主) │ 胸部（大重量复合）+ 肩部          │ 力量为主           │
  ├──────────────┼───────────────────────────────────┼────────────────────┤
  │ Day 2 拉(主) │ 背部（大重量复合）+ 二头          │ 力量为主           │
  ├──────────────┼───────────────────────────────────┼────────────────────┤
  │ Day 3 腿     │ 股四头肌 + 腘绳肌 + 臀大肌 + 腹部 │ 完整腿日           │
  ├──────────────┼───────────────────────────────────┼────────────────────┤
  │ Day 4 推(辅) │ 肩部(弱项) + 三头 + 胸(轻)        │ 增肌容量，侧重弱势 │
  ├──────────────┼───────────────────────────────────┼────────────────────┤
  │ Day 5 拉(辅) │ 二头(弱项) + 斜方肌 + 背(轻)      │ 增肌容量，侧重弱势 │
  └──────────────┴───────────────────────────────────┴────────────────────┘

  原理：5 天意味着有 2 个肌群练两次（推类出现 2 次，拉类出现 2 次），腿只有 1 次因为腿恢复最慢。

  ---
  6天/周

  ▎ PPL × 2：推 / 拉 / 腿 / 推 / 拉 / 腿

  ┌──────────────┬──────────────────────┬─────────────────────┐
  │      天      │       训练内容       │        侧重         │
  ├──────────────┼──────────────────────┼─────────────────────┤
  │ Day 1 推(重) │ 胸部 + 肩部 + 三头   │ 大重量（5-8RM）     │
  ├──────────────┼──────────────────────┼─────────────────────┤
  │ Day 2 拉(重) │ 背部 + 二头          │ 大重量（5-8RM）     │
  ├──────────────┼──────────────────────┼─────────────────────┤
  │ Day 3 腿(重) │ 股四头 + 腘绳肌 + 臀 │ 大重量（5-8RM）     │
  ├──────────────┼──────────────────────┼─────────────────────┤
  │ Day 4 推(轻) │ 胸部 + 肩部 + 三头   │ 增肌容量（10-15RM） │
  ├──────────────┼──────────────────────┼─────────────────────┤
  │ Day 5 拉(轻) │ 背部 + 二头          │ 增肌容量（10-15RM） │
  ├──────────────┼──────────────────────┼─────────────────────┤
  │ Day 6 腿(轻) │ 股四头 + 腘绳肌 + 臀 │ 增肌容量（10-15RM） │
  └──────────────┴──────────────────────┴─────────────────────┘

  原理：同一肌群两次训练间隔刚好 48h。第二次用不同强度和 reps 范围，避免过度训练。
