# 周期路线图组件重构设计

## 背景

ProfilePage 右侧目前堆叠了三个独立组件（CycleRoadmap、PhaseDetail、PhaseVerticalList），展示同一组数据但视觉形式不同，导致严重冗余：当前阶段名出现 3 次、周数出现 2 次、后续阶段重复列出。

## 目标

1. 将三个组件合并为一个**整合组件**，回答 5 个核心问题
2. 不同训练目标（增肌/减脂/塑形/保持健康）显示对应的阶段名和说明
3. 点击阶段胶囊切换说明区内容
4. 说明使用大白话，告诉用户「做什么」和「达到什么目标」
5. 仅在 ProfilePage 右侧展示，MainPage 左侧栏保持精简

## 组件结构

```
┌─────────────────────────────────────┐
│ 🔥 燃脂强化期 · 第 5/16 周   ⏳ 剩余 3 周 │  ← 我在哪 + 倒计时
├─────────────────────────────────────┤
│ 📊 大周期进度           5/16         │  ← 分段着色进度条
│ ▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░             │
├─────────────────────────────────────┤
│ 🌱基础适应 🔥燃脂强化 ⚡代谢提升 🔄减载恢复 │  ← 可点击阶段胶囊
│ 4周 ✅完成  4周 ◉第3/4  4周即将到来 1周即将到来│    每期标注周数
├──────────────────┬──────────────────┤
│ ✅ 本周训练      │ 🧭 下一阶段      │  ← 打卡 + 下一步
│ 2/3              │ ⚡ 代谢提升期    │

├──────────────────┴──────────────────┤
│ 🤔 这个阶段练什么？                  │  ← 点击切换说明
│ 用中等偏重的重量...这样做可以...      │     大白话 + 目标
└─────────────────────────────────────┘
```

### 阶段说明文案（大白话版本）

每个目标×每个阶段的说明，格式统一为：
- **标题：** "🤔 这个阶段练什么？"
- **内容：** "用 XXX 重量/次数，配合 XXX。这样做可以 XXX（达到的目标）。"

#### 增肌

| 阶段 | 说明 |
|------|------|
| 基础适应期 (4周) | 用比较轻的重量先把动作学标准，重点练深蹲、卧推这些基础动作。这个阶段不用着急上大重量，先把姿势练对，以后的训练才能不受伤、效果更好。 |
| 肌肥大期 (4周) | 用中等重量每组做 8-12 下，做到最后几下感觉吃力就对了。这样能给肌肉足够的刺激，让它变大变厚。每次要尝试比上周多做一下或者多加一点点重量，才能持续进步。 |
| 力量提升期 (4周) | 加重重量减少次数，每组做 4-6 下。目标是让神经更高效地调动肌肉，举起更重的重量。这阶段练出来的不只是肌肉，更是实打实的力量增长。 |
| 减载恢复周 (1周) | 重量减轻一半，运动量也减少，让身体彻底恢复。连续练了几个月，身体和神经都很疲劳。这一周就是让身体「充充电」，休息好了下一轮才能练得更好。 |

#### 减脂

| 阶段 | 说明 |
|------|------|
| 基础适应期 (4周) | 用比较轻的重量先把动作学标准，重点练深蹲、卧推这些基础动作。这个阶段即使吃得少一点，身体也能同时长肌肉和减脂肪。先把姿势练对，后面才能全力燃脂。 |
| 燃脂强化期 (4周) | 用中等偏重的重量每组做 8-12 下，配合有氧运动。这样可以一边消耗热量一边给肌肉足够的刺激，不会因为少吃而掉肌肉。这个阶段最关键的是多吃蛋白质（肉蛋奶），才能保住练出来的肌肉。 |
| 代谢提升期 (4周) | 一周里有几天练重一点、有几天练轻一点，配合高强度间歇运动来突破瓶颈。如果减脂速度变慢了，这就说明身体适应了，需要通过变化来重新激活代谢。太累的时候可以安排一两天正常吃饭补充能量。 |
| 减载恢复周 (1周) | 运动量减半，重量也减轻，让身体彻底放松恢复。连续减脂好几个月，身体和神经都很疲劳。这一周就是让身体「充充电」，休息好了下一轮减脂效果才会更好。 |

#### 塑形

| 阶段 | 说明 |
|------|------|
| 基础适应期 (4周) | 用比较轻的重量先把动作学标准，把全身各部位都练一遍。这个阶段重点是找到肌肉发力的感觉，为后续的雕刻塑形打好基础。 |
| 塑形雕刻期 (4周) | 中等重量每组做 10-15 下，重点打磨肩部、背部、臀腿这些部位。目标是让肌肉线条更好看，体态更挺拔。注意动作质量比重量更重要。 |
| 紧致提升期 (4周) | 增加训练强度，复合动作和孤立动作搭配练。这个阶段要练出全身的紧致感，让肌肉轮廓更明显，皮肤看起来更紧实有弹性。 |
| 减载恢复周 (1周) | 运动量减半，重点是拉伸和放松。让肌肉和关节好好恢复，下一轮练起来效果更好。 |

#### 保持健康

| 阶段 | 说明 |
|------|------|
| 基础适应期 (4周) | 从最简单的运动开始，主要以适应为主。不用追求强度，重点是让身体养成规律运动的习惯。每周练 2-3 次比一次练很猛更重要。 |
| 综合维持期 (4周) | 保持中等强度的训练，全身各部位都练到。这个阶段不求突破，主要是维持现有的力量和体能水平，让运动成为生活的一部分。 |
| 活跃恢复期 (4周) | 以轻松愉快的运动为主，增加一些户外活动和有氧运动。保持身体活跃度，享受运动带来的好心情，不给自己太大压力。 |
| 减载恢复周 (1周) | 减少运动量，做一些简单的拉伸和散步。让身体休息一下，为下一轮训练做准备。 |

## 交互行为

1. **点击阶段胶囊** → 仅切换说明区的文字，其他区域全部不动
2. **阶段胶囊状态**：已完成(✅) / 进行中(◉ 第x/4周) / 即将到来(⬜)
3. **说明区**：每个阶段都有对应的「做什么 + 达到什么目标」的大白话解释
4. **进度条**：始终显示当前实际进度，点击不改变
