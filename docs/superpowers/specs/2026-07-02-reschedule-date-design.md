# 调整训练日设计文档

## 概述
在日历面板上提供"调整模式"，让用户可以把本周某个训练日直接拖拽/点击迁移到另一个空闲日期。

## 需求
1. 日历导航栏的「今天」按钮改为「调整日期」按钮
2. 点击进入**调整模式**，在日历网格上完成操作
3. 只能将训练调整到**本周内**的空闲日期
4. **已过期的日期不能作为目标**（date < today，即严格小于今天的不能选；今天及以后的空闲日可选）

## 交互流程

### 进入/退出调整模式
- 按钮位置：日历导航栏 `‹ 2026年7月 › [调整日期]`
- 点击按钮 → 切换调整模式 on/off
- 按钮激活时显示橙色高亮
- 按 ESC 或点击「调整日期」按钮可退出（不保存）

### 调整操作两步走
1. **选源**：点击一个有训练的日期 → 该日期高亮 + 同周空闲日变绿
2. **选目标**：点击一个绿色空闲日 → 调用 API 完成移动 → 自动退出调整模式

### 日历格子的视觉状态

| 状态 | 外观 | 可点击 |
|------|------|--------|
| 已选的源训练日 | 橙色边框 + pulsing | - |
| 同周空闲日（可调整） | 绿色背景 + "空闲"标签 | ✅ |
| 同周已占用日 | 半透明灰 | ❌ |
| 同周已过期空闲日 | 灰色斜线 | ❌ |
| 不同周的日期 | 正常但不可点击 | ❌ |

## 受影响文件
- `frontend/src/components/CalendarPanel.vue` — 主体改动
- `frontend/src/components/DayCell.vue` — 增加调整模式状态样式
- `frontend/src/types/index.ts` — DayCell 可能需要新增 props

## API
复用已有接口：`PUT /api/fitness/day/{day_id}/reschedule`
请求体：`{ "day_of_week": 3 }`

## 复用逻辑
- `DailyPlanPanel.vue` 中已实现的 `doReschedule` 和 `workoutStore.rescheduleDay` 逻辑不变
- 调整完成后刷新日历数据（`cycleStore.fetchCalendarData`）
